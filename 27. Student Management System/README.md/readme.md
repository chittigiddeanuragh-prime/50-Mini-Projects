# 🎓 Student Management System

A desktop-based Student Management System built using Python and Tkinter.  
The application allows users to add, update, delete, search, and manage student academic records through a simple and user-friendly graphical interface.

---

## 📌 Features

- ➕ Add new student records
- ✏️ Update existing student records
- 🗑️ Delete student records
- 🔍 Search students
- 🎯 Filter students by department
- 📊 Automatic dashboard statistics
- 💾 Persistent data storage using JSON
- ✅ Input validation
- ⚠️ Error handling and confirmation messages
- 🎨 Modern and polished Tkinter interface
- 📋 Student records displayed in a table
- ⌨️ Keyboard shortcuts
- 🔄 Reset search and filters
- 📈 Automatic average marks calculation
- 👥 Automatic student and department counting

## 🖥️ Application Overview

The Student Management System provides a dashboard where users can manage student academic information.

### Student Information

The system stores:

- Student ID
- Student Name
- Age
- Gender
- Department
- Course
- Marks

### Dashboard

The dashboard automatically displays:

- Total number of students
- Number of departments
- Average marks

### Search & Filter

Students can be searched using:

- Student ID
- Name
- Department
- Course

Students can also be filtered by department.
